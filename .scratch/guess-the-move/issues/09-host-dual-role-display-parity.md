## Question

The Host wants to also participate and guess alongside everyone else. Since someone still has to run the Session, how does that dual role work?

## Answer

Two separate devices, two separate roles: the Host Display is the PC connected to the beamer and is control-only — it runs the Plenum Selection Phase, triggers Reveal/advance, and shows the shared board and Leaderboard, but never itself submits a Guess. The Host-person can separately join the Session as an ordinary Participant on their own phone, exactly like anyone else.

This makes visibility discipline load-bearing: the Host Display must never show more than a Participant would see before Reveal (see [Round visibility & pacing](../issues/05-round-visibility-pacing.md)), since the Host-as-Participant could otherwise read ahead off the beamer and gain an unfair edge over everyone else in the room.

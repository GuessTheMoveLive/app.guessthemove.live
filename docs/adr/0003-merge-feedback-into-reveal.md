# Merge Feedback into Reveal

**Status**: accepted

Feedback was a separate, Host-triggered phase after Reveal, offered as an alternative to advancing straight to the next Round — in practice, running live sessions, the Host almost always clicked Reveal, then Feedback, then Next Round anyway, making the extra step and extra click redundant rather than a genuine choice point. We decided to retire Feedback as a distinct phase: every Participant now automatically receives their Round Score, whether their Guess matched the Featured Side's actual move, and the Variant explanation as part of Reveal itself, with no separate Host action. The Host Display's Reveal screen takes the slot Feedback used to occupy, showing the Guess Group breakdown instead (see Share Guess Groups in GLOSSARY.md) — the Host's one remaining optional choice at Reveal is whether to share that breakdown with the room, not whether to explain scores.

## Consequences

The Host can no longer skip the score explanation for a Round they want to blow through quickly — every Participant gets it whether the Host wants to spend time on it or not. This was accepted as the right trade: the explanation is personalized and silent (each Participant reads their own phone), so it doesn't cost the room any shared time the way the old Feedback phase did.
